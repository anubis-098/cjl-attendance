# ภาษาไทยและอังกฤษ

เลือกภาษาได้ที่มุมขวาบนในพื้นที่ทำงานและหน้า Login จำค่าต่อเบราว์เซอร์ด้วย `localStorage` คีย์ `cj-language` และใช้ไทยเป็นค่าเริ่มต้น
การสลับภาษาอัปเดต React โดยไม่ reload หรือ remount ฟอร์ม จึงรักษาตัวกรองและข้อมูลที่กำลังกรอกไว้ ค่าภาษาจะซิงก์ระหว่างแท็บ

- `lib/translations.ts`: คำแปลข้อความ UI ไทย→อังกฤษ และข้อความอังกฤษเดิม→ไทย
- `lib/i18n.ts`: `useTranslation()` ให้ `t()` และ `getLocale()` ตามภาษาที่เลือก
- `components/language-switcher.tsx`: ปุ่มเลือกภาษา
- `components/language-provider.tsx`: โหลดภาษาที่จำไว้ และเปลี่ยน `html.lang`

ใช้ `t()` เฉพาะข้อความระบบและป้ายกำกับ ไม่ใช้กับชื่อพนักงาน ชื่อบัญชี แผนก Agency ชื่อไฟล์ หรือข้อความที่ผู้ใช้กรอก
วันที่แสดงตาม locale (ไทยใช้ปี พ.ศ. อังกฤษใช้ปี ค.ศ.) แต่ค่าที่บันทึกยังเป็นรูปแบบ ISO และกะยังอิงเวลา Asia/Bangkok
ไฟล์ต้นทาง ตัวอย่าง CSV และ CSV ส่งออกยังใช้รูปแบบ/หัวตารางเดิม เพื่อให้การนำเข้าและงานเงินเดือนต่อเนื่องกัน ตัวอย่าง CSV ในหน้าต่าง Export จะแสดงตรงกับไฟล์จริง
การสลับภาษาไม่แก้ข้อมูลใน SQL และไม่เปลี่ยนสิทธิ์บัญชี
