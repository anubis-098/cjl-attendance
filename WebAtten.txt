เรื่อง: อัปเดตเว็บไซต์ CJ Agent ประจำวันที่ 11 ตุลาคม 2569
เรียน หัวหน้างาน

ขอสรุปการปรับปรุงล่าสุดของระบบตรวจสอบเวลาทำงานและโอที เพื่อให้ตรวจข้อมูลได้ง่ายขึ้น และลดปัญหาการจับคู่เวลาเข้า–ออกผิดพลาด ดังนี้

1. ทำการติดตั้ง Server และทำการอนุญาตเว็บไซต์ cj.attendance.co.th จาก HDC ผ่าน Firewall มาที่ CDC เรียบร้อย
Local Server -> HDC Firewall <-> CDC Firewall -> CDC Internal Network

2. Finger Service v1.4.11
โปรแกรมเบื้องหลังที่คอยดึงข้อมูลสแกนนิ้วจาก WEB8 มา แล้วนำเข้าข้อมูลสแกนนิ้วสู่ระบบเว็บไซต์อัตโนมัติ จะทำงานอัตโนมัติทุก ๆ 30 นาที เป็นโปรแกรมมาโครอัจริยะแบบนึงที่จะอ่านหน้าตาโปรแกรม WEB8 แล้วทำการคลิกตามลำดับที่กำหนดไว้ ไม่ได้ทำงานแบบ 1 2 3 แต่เป็นการอ่านหน้าต่างโปรแกรมและกำหนดเงื่อนไขต่าง ๆ เพื่อป้องกันความผิดพลาดให้มากที่สุด ทำให้โปรแกรมรันแบบอัตโนมัติแบบ 24/7
(https://github.com/anubis-098/finger_service/releases/tag/v1.4.11)

3. ปรับการจับคู่เวลาสแกนนิ้ว
ปรับเงื่อนไขรองรับการทำงานข้ามคืน การทำงานต่อเนื่องหลายชั่วโมง และการเปลี่ยนเวลาเข้างาน โดยตรวจจากข้อมูลสแกนจริงร่วมกับประวัติการทำงาน กรณีที่ยังแยกเวลาเข้า–ออกได้ไม่ชัดเจน ระบบจะแสดงให้หัวหน้างานตรวจสอบ ไม่ยืนยันข้อมูลให้อัตโนมัติ

4. เพิ่มการจับคู่เวลาเข้า–ออกด้วยตนเอง
ในปฏิทินพนักงาน สามารถลากเชื่อมเวลาสแกนเข้าและออก หรือคลิกเลือกสองเวลาแล้วกดยืนยันได้ รองรับการทำงานข้ามวัน พร้อมบันทึกผู้แก้ไขและประวัติย้อนหลัง โดยเก็บข้อมูลสแกนต้นฉบับไว้ การจับคู่เวลาเป็นคนละขั้นตอนกับการยืนยันโอที

5. ยกเลิกการแสดงเวลาทำงานคาดเดา 8 ชั่วโมง
เมื่อสแกนไม่ครบ จะแสดงจุดเวลาสแกนจริงพร้อมเครื่องหมายสีแดง แทนการสร้างคาบทำงานเพิ่มเอง เพื่อไม่ให้เข้าใจว่าเวลาที่คาดเดาเป็นเวลาทำงานจริง

6. ปรับตัวกรองและปุ่มเลือกวันที่ให้อ่านง่าย
ตัวกรองที่กำลังใช้งานจะแสดงขอบสีฟ้าและพื้นสีฟ้าอ่อน เมื่อล้างค่าจะกลับเป็นสีปกติ ใช้กับหน้าภาพรวมเวลาทำงาน รายการรออนุมัติ และหน้ารายงานที่เกี่ยวข้อง ส่วนปุ่มช่วงเวลาที่เลือกและปุ่ม “วันนี้” เปลี่ยนเป็นสีน้ำเงิน ช่วยให้สังเกตเงื่อนไขที่กำลังดูได้ชัดเจน

7. แสดงคำอธิบายสถานะด้วยสีและสัญลักษณ์
เปลี่ยนข้อความยาวบนปฏิทินเป็นรายการสัญลักษณ์สั้น ๆ ได้แก่
- สีฟ้า: ทำงานปกติ
- สีเหลือง: มีโอที
- สีเขียว: ยืนยันแล้ว
- สีแดง: สแกนไม่ครบหรือยังต้องตรวจสอบ
แต่ละสถานะมีข้อความกำกับ เพื่อให้เข้าใจได้โดยไม่ต้องอาศัยสีเพียงอย่างเดียว

ขั้นตอนถัดไป
ให้ผู้ใช้งานทดลองตรวจคู่เวลาเข้า–ออกและรายการโอที โดยเฉพาะพนักงานที่เปลี่ยนกะหรือทำงานข้ามคืน ทั้งนี้การจับคู่ด้วยตนเองในปัจจุบันรองรับหนึ่งคู่ต่อวันเริ่มงาน และระยะเวลาไม่เกิน 24 ชั่วโมง

วัตถุประสงค์
รวบรวมข้อมูลพนักงานและเวลาสแกนนิ้วไว้ในระบบเดียว เพื่อช่วยหัวหน้างานตรวจสอบการมาทำงาน ยืนยันโอที และสรุปค่าใช้จ่าย ลดการตรวจเทียบและคำนวณด้วยมือจากหลายไฟล์

1. เว็บไซต์ CJ Agent
- นำเข้าข้อมูลพนักงานและเวลาสแกนนิ้ว โดยเพิ่มข้อมูลใหม่ ข้ามรายการซ้ำ และเก็บข้อมูลเดิมไว้
- แสดงเวลาทำงานจริงในตารางและปฏิทินรายบุคคล รองรับงานข้ามคืน พร้อมเก็บกะตามแผนไว้เปรียบเทียบ
- หัวหน้างานกำหนดกะ วันหยุด วันลา หมายเหตุ ขอและยืนยันโอที รวมถึงตรวจหลักฐานกรณีสแกนไม่ครบได้ พร้อมประวัติการแก้ไขย้อนหลัง
- สรุปค่าจ้าง โอที และเบี้ยเลี้ยงรายเดือน เลือกพนักงานและส่งออกรายงาน CSV เพื่อเปิดใน Excel ได้
- ปรับค่าจ้างฐานและโอทีให้รวมค่า Service 8% เช่น ฐาน 357 บาท เท่ากับ 385.56 บาทต่อวัน และ OT x1.0 เท่ากับ 48.20 บาทต่อชั่วโมง โดยเบี้ยเลี้ยงยังเป็นอัตราคงที่
- กำหนดค่าจ้างส่วนกลางและรายบุคคลได้ เฉพาะ Super Admin แก้ไขอัตราเงิน ส่วน Supervisor ดูข้อมูลการเงินและดำเนินงานตามสิทธิ์ได้
- รองรับภาษาไทยและอังกฤษ และแยกบัญชีผู้ใช้งานตามหน้าที่

สถานะเว็บไซต์: พัฒนาฟังก์ชันหลักแล้ว มีการปรับการจับคู่สแกนและคำนวณเงินตามข้อกำหนดล่าสุด รายการสแกนไม่ครบหรือกำกวมยังต้องให้หัวหน้างานตรวจสอบก่อนยืนยัน ยอดเงินเป็นยอดก่อนภาษีและรายการหัก ไม่ใช่ยอดสุทธิพร้อมโอน

2. โปรแกรม Finger Service
ทำหน้าที่กดดึงข้อมูลจาก WEB8 NEXT บันทึกเป็นไฟล์ และส่งเข้าเว็บไซต์ตามการตั้งค่า ดึงย้อนหลัง 3 วันถึงวันปัจจุบัน ทำซ้ำทุก 30 นาทีหลังผู้ใช้กด Start มีปุ่มยกเลิกและบันทึกเหตุขัดข้อง หากส่งไฟล์ไม่สำเร็จจะเก็บไว้ส่งใหม่

ความคืบหน้าล่าสุด: เผยแพร่เวอร์ชัน 1.4.4 บน GitHub แล้ว
- เพิ่มตัวช่วยอ่านข้อความจากภาพ (OCR) บน Ubuntu + Xfce เพื่อใช้งานร่วมกับ Wine
- แก้สาเหตุที่โปรแกรมเปิดขึ้นมาแล้วไม่คลิก โดยเปลี่ยนวิธีควบคุมหน้าต่างให้หลีกเลี่ยงคำสั่งที่ Wine ไม่รองรับ
- เพิ่มการตรวจช่องกรอกและตำแหน่งการพิมพ์ก่อนส่งข้อมูลล็อกอิน หากผิดพลาดให้ลองใหม่ และหยุดเมื่อไม่สำเร็จครบ 3 ครั้ง
- ทดสอบกับโปรแกรมจำลองบน Windows โดยใช้วิธีควบคุมแบบใหม่ ผ่านตั้งแต่ล็อกอิน เลือกวันที่ รอข้อมูล จนบันทึกไฟล์ รวมถึงกรณีโฟกัสหลุดและล็อกอินผิดซ้ำ

ข้อจำกัด: ยังต้องทดสอบครบกระบวนการกับ WEB8 NEXT จริงบน Ubuntu + Wine ต้องเปิดหน้าจอและปลดล็อกไว้ และภาษาไทยต้องแสดงถูกต้องเพื่อให้ OCR อ่านได้ จึงยังไม่ยืนยันความพร้อมสำหรับใช้งานอัตโนมัติต่อเนื่องบนเครื่องจริง

3. งานถัดไป
- ติดตั้ง Finger Service 1.4.4 บนเครื่องต้นทางจริง และตรวจการดึงข้อมูลหลายรอบให้ทำงานต่อเนื่อง
- ตรวจว่าไฟล์ที่ส่งเข้าเว็บไซต์มีจำนวนรายการและเวลาเข้า–ออกตรงกับต้นทาง
- ให้หัวหน้างานตรวจรับตัวอย่างการคำนวณค่าจ้างและโอที ก่อนนำรายงานไปใช้ประกอบการจ่ายเงินจริง

ผลที่คาดว่าจะได้รับ
ลดงานกดดึงไฟล์และตรวจเทียบข้อมูลซ้ำ ช่วยให้เห็นรายการผิดปกติเร็วขึ้น และตรวจสอบที่มาของยอดค่าใช้จ่ายย้อนหลังได้ ทั้งนี้ยังต้องเก็บผลใช้งานจริงเพื่อประเมินเวลาที่ประหยัดได้
